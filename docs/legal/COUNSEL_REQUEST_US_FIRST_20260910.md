> **요청 성격**: 아래 **7건에 대한 회신만** 우선 요청드립니다.
> **회신 목표**: 2026-09-17
>
> 기존 `LAWYER_BRIEF v1.0`(2026-07-21, Q1~Q30)의 나머지 항목은 **이번 요청 범위가
> 아닙니다.** 7개 관할 전체가 아니라 **미국 단독 개시**에 필요한 것만 좁혔습니다.

## 0. 왜 범위를 좁혔는가

현재 서비스는 **어느 관할에서도 승인된 약관·방침 없이 운영 중**입니다. 7개 관할
전건 회신을 기다리는 동안 그 상태가 유지되므로, **미국 하나만 먼저 정상화**하는
경로를 택했습니다. 나머지 관할은 그 뒤에 순차 요청드립니다.

## 1. ★ 회신 전에 알고 계셔야 할 현재 사실

**아래는 추정이 아니라 실측된 현재 상태입니다.** 질의의 전제이므로 먼저 적습니다.

```
[F-1] 공개 URL 에 미해결 표기가 노출 중
      https://api.pigos.io/legal/privacy?lang=en  및  ?lang=ko
      본문에 [V] 11개 · [OPEN] 10개 · [COUNSEL] 1개 · 빈 대괄호 2개 = 24개
      → 사내 검토용 표기가 제거되지 않은 채 공개 게시되어 있습니다.

[F-2] 법무 문서 8종 전부 미승인 초안
      MASTER_TERMS · GLOBAL_PRIVACY_NOTICE · ADDENDUM ×6 (US·EU·GB·BR·TH·VN)
      전부 v0.1-draft / DRAFT_LAWYER_PENDING

[F-3] 동의 기록이 저장되지 않고 있었음
      가입자의 동의 원장(consent_ledger) 행 수 = 0
      원인은 시스템 결함(트랜잭션 미확정)이며 수정 코드는 완료·미배포 상태입니다.
      → 즉 현재 가입자 전원에 대해 "동의를 받았다"는 기록이 없습니다.

[F-4] 미승인 초안 문서로 동의를 수집해 왔음
      화면에 초안 경고는 표시되나 제출을 막지 않았습니다.
      초안 상태에서 동의를 받지 않도록 하는 수정은 완료·미배포 상태입니다.

[F-5] 가입 차단 관할에 기존 계정 존재
      한국·중국은 신규 가입을 차단하고 있으나 기존 계정의 로그인은 차단되지 않습니다.
      (계정 수는 사내 확인 중)
```

## 2. 질의 7건

### Q-A. 미해결 표기가 남은 방침을 공개 게시 중인 상태의 위험

`[F-1]` 상태입니다.

```
① 즉시 내려야 하는지, 정정본 게시로 충분한지
② 그 사이 수집된 개인정보의 적법성에 영향이 있는지
③ 내릴 경우 방침 부재 상태가 되는데, 그것과 미해결 표기 게시 중
   어느 쪽 위험이 큰지
```

### Q-B. 미국만 무료 가입을 여는 데 필요한 최소 문서 세트

```
MASTER_TERMS (이용약관)
GLOBAL_PRIVACY_NOTICE (개인정보 처리방침)
ADDENDUM_US (미국 부속조항)
```

**이 3종 승인으로 미국 내 무료 가입을 개시할 수 있는지**, 추가로 필요한 문서가
있는지 확인 부탁드립니다.

### Q-C. D-01~D-04 사내 조건부 결정에 대한 이견 여부

2026-07-21 사내에서 조건부 승인한 4건입니다. **변호사 이견이 있으면 자동 재검토**
합니다.

```
D-01  국가별 익명통계 분기
D-02  목적 ③④⑤ 옵트인 처리
D-03  20년 보유 후 삭제
D-04  소급 회수 범위 한정
```

### Q-D. controller / processor 역할 확정

처리 유형별 역할 매핑입니다. (`LAWYER_BRIEF` D-13 과 동일 건)

### Q-E. BR SCC 전문 편입 없이 파일럿 가능 범위

브라질 표준계약조항 전문을 편입하지 않은 상태에서 **파일럿으로 가능한 범위**가
있는지, 아니면 전면 불가인지.

### Q-F. 동의 기록이 없는 기존 가입자의 계약 성립

`[F-3]`·`[F-4]` 상태입니다.

```
① 사후 동의 수락으로 치유되는지
② 계약 성립 자체를 다시 보아야 하는지
③ 다시 보아야 한다면, 그 사이 축적된 농장 데이터의 처리 근거는 어떻게 되는지
```

★ **이 질의가 이번 요청에서 가장 중요합니다.** 현재 전 가입자가 해당됩니다.

### Q-G. 미국 승인이 부속조항 없는 전 국가까지 여는 구조

시스템 구조상, 관할별 부속조항이 있는 국가는 그 부속조항이 승인되어야 가입이
열립니다. **부속조항이 없는 국가는 마스터·방침 2종만으로 완성된 문서 세트**가
되므로, 미국 3종을 승인하면 **부속조항이 없는 모든 국가가 함께 열립니다.**

```
함께 열림    멕시코 · 칠레 · 콜롬비아 · 일본 등 (별도 부속조항 없음)
계속 차단    브라질 · 베트남 · 태국 · EU · 영국 (각자 부속조항이 미승인)
```

```
① 마스터·방침 2종만으로 해당 국가들에 서비스를 제공해도 되는지
② 아니라면, 해당 국가들을 별도로 차단해야 하는지
   (시스템상 "부속조항 없는 국가 전체" 단위 차단이 가능합니다)
```

★ 참고: 해당 국가군은 사내 법무 리서치가 완료되지 않은 시장입니다.
