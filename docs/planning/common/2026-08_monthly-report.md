| LEGAL-P0-WEB-CONSENT-FAIL-CLOSED | ✅ 코드완료 | 동의 기록이 성공해야 로그인 확정. 이전엔 실패를 삼키고 진입했다 |
| LEGAL-P0-CONSENT-FARM-AUTHORITY | ✅ 코드완료 | 남의 `farm_id`로 동의 행을 남길 수 있던 권한 결함 차단. 듀얼 리뷰로 1차 구현 결함 2건 발견·수정 |
| LEGAL-P0-CONSENT-LEDGER-PERSISTENCE | ✅ 코드완료 | **동의 기록이 커밋되지 않아 매번 rollback**되던 것 수정. 200을 주고 아무것도 저장하지 않고 있었다 |
| LEGAL-P0-MANDATORY-CONSENT-LOGIN-GATE | ⏸ 대기 | 로그인 경로에 동의 판정이 없다. **사람 결정 선행** — 지금 켜면 승인 문서가 없어 아무도 로그인 못 한다 |

> ⚠️ **위 5건은 전부 로컬 커밋이며 배포되지 않았다.** 코드가 고쳐진 것과 서비스가
> 고쳐진 것은 다르다. 라이브 PigOS는 여전히 예전 동작이다.

## 5. 9~12월 제안

> ⚠️ **승인된 계획이 아니라 제안이다.** 조건 게이트와 결정 레지스터에서 도출했고
> 대표·법무 결재를 거치지 않았다. 날짜를 약속으로 읽지 말 것 — 각 분기 실행 여부는
> 앞선 게이트가 열리는지에 달려 있고, **그 게이트는 개발이 열 수 없다.**

### 9월 (남은 3주) — 동의 원장을 실제로 돌아가게 만든다

| 항목 | 선행 조건 |
|---|---|
| iOS 동의 연동 (현재 동의 API 호출 0건 — 원장이 비는 유일 클라이언트) | 없음 |
| 동의 증빙 보강(로케일·문서 해시·채널) | 스키마 변경 → 승인 필요 |
| 법무 P0 5건 한 세트 재검증 후 **배포** | 배포 승인 |
| 기능 매트릭스 결재 상신 | — |

> 개발이 단독으로 진행 가능한 마지막 구간이다.

### 10월 — 팔 물건의 경계를 코드로 만든다

| 항목 | 선행 조건 |
|---|---|

| 경영관리(운영비·손익) 기능 — 회의에서 요구된 무료 P0 | 상동 |
| 미국 시장 KPI 실사 마무리 (국가 추가에 코드 변경이 필요한지 확인) | — |
| 모바일 2개 저장소에 API 계약 변경 반영 | 서버 배포 완료 |
