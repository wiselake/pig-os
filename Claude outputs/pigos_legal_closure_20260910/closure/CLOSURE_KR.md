# CLOSURE_KR — 한국 (2026-09-10)

> **PigOS 는 KR 비대상이다.** `_GATES["KR"] = signup_blocked, reason_code="KR_REFERENCE_ONLY"` (`jurisdiction.py:66`). 부속조항 없음 (`_ADDENDUM["KR"] = None`).
> A-rule: 한국 벤치마크·한돈팜스 데이터는 PigOS 판매 경로·외부 API·마케팅에 나타나지 않는다. 내부 참조 기준선으로만.
> 이 시트의 대상은 **피그플랜 현행 게시본**(공고 2026-04-30 · 시행 2026-05-30)이다 — PigOS 문서의 **선례이자 재동의 리스크의 원천**이지 PigOS 게시 대상이 아니다.

## 0. 판정

```

피그플랜    별도 트랙. 이 프로젝트에서 자동 생성·정비하지 않는다 (HUMAN_INPUT_QUEUE §0 위조0 규율).
           단 F5 (동의 모델 상충) 는 D-01~D-04 의 사실 전제라 PigOS 결정과 분리되지 않는다.

★ 게시 언어 문제 (H14): 공개 방침 언어 ko·en 중 ko 는 PigOS 비대상 국가의 언어이고,
  정작 법정 요건 언어 pt-BR·th·vi 는 없다. 언어 세트가 법역 정책과 반대로 붙어 있다.
```

## 3. KR 이 PigOS 에 남기는 실제 리스크

| 리스크 | 심각도 | 근거 | 처리 |

| 콜드 이메일 KR 발송 (정통망법 옵트인, B2B 예외 없음) | HIGH | Q17 · D-10 · **V5 발송 현황 미확인** | 실행 여부 확인이 먼저. 발송 중이면 즉시 중단 |
